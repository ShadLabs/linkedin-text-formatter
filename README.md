# LinkedIn Text Formatter

A lightweight browser-based tool for writing, formatting, previewing, and copying LinkedIn posts using Unicode text styles.

## ✨ Features

- Bold text
- Italic text
- Bold + italic text
- Monospace text
- Strikethrough
- Bullet lists
- Numbered lists
- Live LinkedIn-style preview
- Character counter
- Word counter
- Undo and redo
- Keyboard shortcuts
- Post templates
- Copy to clipboard
- Dark mode
- Persistent theme preference using localStorage
- Editable profile preview
- Responsive design
- Privacy-friendly — formatting happens entirely in the browser

## 🛠️ Built With

- HTML5
- CSS3
- Vanilla JavaScript
- Unicode Mathematical Alphanumeric Symbols
- Clipboard API
- Web Storage API
- DOM API

## ⌨️ Keyboard Shortcuts

| Shortcut | Action |
| --- | --- |
| `Ctrl + B` / `Cmd + B` | Bold |
| `Ctrl + I` / `Cmd + I` | Italic |
| `Ctrl + Z` / `Cmd + Z` | Undo |
| `Ctrl + Shift + Z` / `Cmd + Shift + Z` | Redo |

## 🚀 How It Works

LinkedIn posts do not support traditional rich-text formatting such as HTML bold and italic tags.

This tool converts regular characters into visually styled Unicode characters that can be copied and pasted into LinkedIn posts.

For example:

Normal:

Hello LinkedIn

Bold:

𝐇𝐞𝐥𝐥𝐨 𝐋𝐢𝐧𝐤𝐞𝐝𝐈𝐧

## 🔒 Privacy

Your post content is not uploaded to a server.

All formatting and preview functionality runs locally inside your browser.
